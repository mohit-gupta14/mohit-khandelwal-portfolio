# Mohit Khandelwal — Personal Portfolio Website

A mobile-app-inspired personal portfolio website for **Mohit Khandelwal**, Senior Full-Stack & Mobile Software Engineer (React Native, Next.js, Node.js, AWS & Applied AI).

## 🚀 Tech Stack
- **Framework:** React 18 + TypeScript + Vite
- **Styling:** Tailwind CSS v4 + Custom iOS Design Tokens
- **Animations:** Framer Motion (Spring physics & gestures)
- **Icons:** Lucide React
- **PDF Generation:** PDF-Lib (Generates authentic 2-page CV download asset)
- **Deployment:** Vercel (Configured with `vercel.json` for SPA rewrites & direct file download headers)

## 📦 Getting Started

### Install Dependencies
```bash
npm install
```

### Run Locally (Development Server)
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### Build for Production
```bash
npm run build
```
The compiled, production-ready static assets will be output to `dist/`.

### Preview Production Build
```bash
npm run preview
```

## 🌐 Deploy to Vercel
Deploy in one command:
```bash
npx vercel
```
Or import directly from your GitHub repository to Vercel.
